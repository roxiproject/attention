## attention_lib

A from-scratch, numpy-only Python library implementing core attention
mechanisms used in transformer models. No torch, no other ML framework —
just numpy and the math.

### What's implemented

- **Scaled dot-product attention** (`attention_lib/sdpa.py`) — numerically
  stable softmax (max-subtraction trick), optional causal masking, optional
  arbitrary boolean mask. Verified against an independent explicit-loop
  reference implementation.
- **Multi-head attention** (`attention_lib/multihead.py`) — head
  split/combine with correct reshape/transpose semantics, verified against
  a fully independent per-head, per-position nested-loop reference.
- **Grouped-query attention / multi-query attention** — shared KV heads
  across groups of query heads (`grouped_query_attention`), with
  multi-query attention as the `num_kv_heads == 1` special case.
- **Rotary position embeddings (RoPE)** (`attention_lib/positional.py`) —
  proper 2D-pair rotation math, checked against hand-computed values for
  small cases (e.g. base=1, single frequency, known rotation angles), plus
  the defining relative-position property: `dot(rope(q, m), rope(k, n))`
  depends only on `m - n`.
- **T5-style relative position bucketing** — log-bucketed relative
  position indices for use with a learned bias table.
- **KV-cache incremental decoding** (`attention_lib/kv_cache.py`) —
  appending one token's key/value at a time to a cache and decoding
  step-by-step produces output *bit-for-bit close* (`atol=1e-8`) to a full
  batched forward pass over the same sequence, with and without RoPE. This
  equivalence is the actual correctness bar for a KV cache and is tested
  explicitly.

### Running the tests

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
pytest -q
```

All ~80+ tests are real: shape checks, numerical-stability checks (large
and very negative logits), invariance properties (norm preservation under
rotation, linearity of attention in V, batch independence), and
cross-checks against independently-written reference implementations
rather than against the code under test.

### Benchmarks

`benchmarks/bench_sdpa.py` times a naive explicit-Python-loop attention
implementation against the vectorized numpy version on the same random
inputs (asserting they agree numerically before timing). On this machine,
vectorized attention is roughly 100-300x faster than the loop version as
sequence length grows from 32 to 256.

`benchmarks/bench_gqa.py` compares wall-clock and KV-tensor memory
footprint of grouped-query attention as the number of shared KV heads
shrinks from 16 (standard MHA) down to 1 (multi-query attention).

Run either with:

```bash
python benchmarks/bench_sdpa.py
python benchmarks/bench_gqa.py
```
